# Four tiers of mail

Replied-or-starred mail in full for all time; a configurable recent window (24 months by default) of other
inbox mail judged per sender by a small model with deterministic caps; every other message as a header row
plus its raw body stored as evidence; `read_email` for the rest, live. Reading everything with a model costs
dollars and adds noise; reading only conversations misses offers, notices, and receipts. Sender engagement
orders the raw reads inside that window ([[Engagement orders inbox reads]]). The reviewer confirmed this
scope is acceptable.
