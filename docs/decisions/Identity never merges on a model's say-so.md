# Identity never merges on a model's say-so

Entity resolution is deterministic: exact unique email, then an established alias, then a first name inside
a compatible organization. Ambiguity creates separate profiles and a merge candidate, never a silent merge.
Clustering may union variants because a cluster is only a candidate pool for the judge, not an identity
claim. Known cost: the same person can have one profile per address.
