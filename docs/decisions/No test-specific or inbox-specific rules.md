# No test-specific or inbox-specific rules

The user's hard rule: nothing in the code may target this inbox, a sender, a vendor, or a benchmark item;
rules are allowed only when general, free, and sensible for any mailbox; prompt examples use neutral names.
Two audits and a name grep enforce it. Gate relaxations were justified by tracing every judge proposal, not
by test items. Related: [[Working conventions]].
