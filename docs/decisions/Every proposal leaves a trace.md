# Every proposal leaves a trace

Aggregate rejection counters explain a population but not one proposed concept. Every raw judge proposal now
keeps its source cluster, citations, each named gate and dedupe outcome, whole-list review disposition, second
gate pass, and final file or drop stage. `concepts/TRACE.md` renders later stages first, and the same structured
rows live in `concepts.json`. The trace is observational: accepted lists and aggregate counters retain their
existing values, and no prompt receives trace metadata. Related: [[Concept layer]],
[[Every claim cites a thread and a day]].
